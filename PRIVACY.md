# Privacy policy

Lightbox for GitHub collects no data.

- The extension runs only on pages at `https://github.com/`.
- It reads the images and videos in the page to show them in the lightbox. The page already loaded that media.
- It sends nothing to any server. It has no analytics and no tracking.
- It stores nothing. It uses no cookies, no `chrome.storage`, and no browser storage.
- It asks Chrome for no permissions.

The source code is public: https://github.com/brunojppb/gh-lightbox

Questions go to the issue tracker: https://github.com/brunojppb/gh-lightbox/issues
